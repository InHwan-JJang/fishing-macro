# v1.3.1 패치노트

자동어 해제 흐름을 개선하고, 디버깅 로그와 운영자 출현 보상 기록을 추가했습니다.

## 자동어 해제

- 자동어 감지 시 다음 사이클에 `수동`, 그다음 사이클에 `낚시`를 전송합니다.
- 정상 낚시 성공 시 해제 횟수를 초기화합니다. 3회 해제 후에도 자동어가 나오면 안내와 함께 중단합니다.
- 낚시와 수동의 입력 간격 및 답장 대기를 통일하고, 기존 실패 대기의 복귀 문제를 제거했습니다.

## 디버깅 로그

- 실행 파일 옆 `debug/fishing-macro.log`에 한국 시간, 실행 환경, 명령·응답, 재시도, 대기 사유, 예약, 히스토리 처리와 예외 traceback을 기록합니다.
- 파일당 10 MiB, 이전 파일 5개까지 순환 보관합니다. 문제 발생 시 발생 시각과 debug 폴더를 함께 전달해 주세요.
- 로그에는 닉네임, 봇 응답, 게임 기록과 로컬 경로가 포함될 수 있습니다.

## 운영자 출현 보상

- 운영자 출현을 별도 이벤트로 인식하여 다음 낚시를 계속합니다.
- 메시지에 표시된 골드·진주·미끼·해신석을 저장하고 전체 목록과 보상 요약에 표시합니다.
- 반복 복사의 중복 집계, 다른 사람이나 다음 물고기에 보상이 섞이는 것을 방지합니다.
- 기존 CSV와 호환되며 운영자 이벤트는 물고기 판매수익·등급 분포·행운 소비에 포함하지 않습니다.

## 검증 및 업데이트

- 자동 테스트 133개 통과. 실제 카카오톡 입력을 통한 실행 검증은 진행하지 않았습니다.
- 기존 프로그램을 종료하고 `FishingMacro_v_1_3_1.exe`를 기존 실행 파일과 같은 폴더에서 실행하세요.
- 기존 `fishing-macro-history` 폴더는 유지하세요.
