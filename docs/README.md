## 버전 관리

- 수정·테스트·로컬 빌드만으로 버전 번호를 올리지 않습니다. 실제 릴리즈 시에만 변경합니다.
- 현재 기준 버전은 `1.4.1`이며, 이후 작업 중인 내용은 문서에 `미릴리즈 변경`으로 표시합니다.
- [v1.4.1 패치노트](release-v1.4.1.md)
- [v1.4.0 패치노트](release-v1.4.0.md)
- 미릴리즈 실행 파일은 `FishingMacro_dev.exe`처럼 릴리즈 번호 없이 구분합니다.
- 이전 작업 중 붙인 `1.3.4`~`1.3.8` 표기는 로컬 빌드에 잘못 붙인 번호이며 릴리즈를 의미하지 않습니다.
