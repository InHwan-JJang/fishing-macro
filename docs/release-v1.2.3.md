# v1.2.3 패치노트

## 핵심 요약

- **히스토리 탭 개편**: 구간별 통계를 별도 버튼에서 `구간` 탭으로 옮기고, `행운 기록`과 `도감 완성` 탭을 `행운`, `도감`으로 정리했습니다.
- **평균 판매값·등급 통계 개선**: 평균 계산에서 추가 낚시를 제외하는 토글과 기록 기반 등급별 비율을 추가했습니다.
- **복권 인식 수정**: 황금빛 복권·연금복권처럼 크기 대신 당첨 등수가 표시되는 카드가 정상적으로 기록되도록 수정했습니다.

## 자세한 변경사항

### 히스토리 탭 및 상세 표시

- 탭 순서를 `전체 / 어종 / 구간 / 행운 / 진주 / 도감 / 자동어 / 레이드`로 변경했습니다.
- 기존 구간별 통계 버튼을 제거하고 어종과 행운 사이에 구간 탭을 배치했습니다. 기존 히스토리 창에서 전환됩니다.
- 등급 선택과 열 제목 클릭 정렬은 유지합니다.
- 추가 낚시 기록의 상세에서 반복되던 `추가 낚시 · 재화·경험치 없음` 문구를 제거했습니다. 추가 낚시 순번, 0% 구간, 골드·EXP 0 표시는 유지합니다.

### 평균 판매값 계산

- `추가낚시 제외 (평균 계산)` 토글을 추가했습니다. 기본값은 꺼짐입니다.
- 토글을 켜면 추가 낚시 단계 또는 판매 구간 0%로 확인되는 기록을 평균 계산에서 제외합니다.
- 토글은 평균 계산에만 적용되며 원본 기록, 표시되는 행, 누적 수, 등급 비율을 변경하지 않습니다.
- 어종 전체 평균, 구간별 평균, 등급별 평균, 행운 소비 평균에 적용됩니다. 계산 대상이 없으면 평균을 `—`로 표시합니다.

### 등급별 실측 비율

- 전체·어종 탭에는 전체 포획 기록의 등급 분포를 표시합니다.
- 행운 탭은 행운을 소비한 포획 기록을 기준으로 계산하며, 행운 부여만 받은 기록은 제외합니다.
- 도감 탭은 도감 완성 포획 기록, 구간 탭은 각 판매 구간의 포획 기록을 기준으로 표시합니다.
- 어종 종류 수가 아닌 포획 횟수를 사용하며, 등급 미확인 기록은 분모에서 제외하고 제외 건수를 표시합니다.
- 특정 등급을 선택해도 비율은 선택 전 분포를 유지합니다. 진주·자동어·레이드에는 등급 비율을 표시하지 않습니다.
- 이 수치는 저장된 기록의 실측 비율이며 게임의 공식 출현 확률이 아닙니다.

### 복권 및 특수 획득물 인식

- 추가 낚시 응답의 `[레어] 이름 · 당첨 결과` 요약 줄 이후에도 실제 카드를 계속 찾도록 수정했습니다.
- 황금빛 복권과 연금복권의 이름·등급·누적 수를 기록하고, 크기는 `—`, 상세에는 `3등 당첨` 등 카드의 결과를 표시합니다.
- 뒤이어 낚은 물고기가 복권 기록에 잘못 연결되는 문제를 방지합니다. 기존 강화 수치 장비 카드 처리도 유지합니다.
- 당첨 결과는 기존 CSV 필드에 저장하므로 별도 파일 변환 없이 저장·불러오기가 가능합니다. 이미 잘못 저장된 과거 기록은 자동 복구하지 않습니다.

## 검증 및 업데이트

- 자동 테스트 101개 통과: 탭 이동, 평균 포함·제외, 등급 비율, 복권 카드와 후속 물고기 연결, 반복 복사, CSV 저장·불러오기 등을 검증했습니다.
- 실제 카카오톡 입력 검증은 진행하지 않았습니다. 연금복권은 동일한 카드 형식을 가정한 테스트이며 실제 복사 원문은 아직 제공되지 않았습니다.
- 기존 프로그램을 종료한 뒤 `FishingMacro_v_1_2_3.exe`를 기존 실행 파일과 같은 폴더에서 실행하세요. `fishing-macro-history` 폴더는 유지하세요.
