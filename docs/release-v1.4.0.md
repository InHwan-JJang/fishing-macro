# v1.4.0 패치노트

낚시 명령과 대화 복사 순서를 정리하고, 일시중단 후 재개 및 어종 미확인 기록 복구를 개선했습니다.

## 낚시 입력 및 대화 확인

- `@ → Enter → 낚시 → Enter → 선택 → 복사` 순서로 진행합니다. 자동어 감지 시에는 `낚시` 대신 `수동`을 입력한 뒤 다시 낚시를 진행합니다.
- Enter 재입력과 봇 언급·명령 전송 여부 확인을 제거했습니다. 문자 입력 완료 후 0.5초 간격을 유지합니다.
- 마지막 Enter 후 0.5초에 대화를 검사하고, 응답을 확인하지 못했을 때만 2.5초에 한 번 더 검사합니다. 첫 검사에서 응답을 찾으면 두 번째 복사는 생략합니다.
- 두 번 모두 응답을 확인하지 못해도 3초 대기 종료 후 다음 낚시 사이클로 진행합니다. 미확인 결과를 성공 횟수에 더하지는 않습니다.
- 복사가 완료되기 전에 입력창으로 포커스를 옮기지 않도록 변경했습니다. Ctrl+A·Ctrl+C의 키 누름과 뗌은 각 조합별로 묶어 전송합니다.

## 일시중단 후 재개

- 입력 도중 채팅방 포커스를 잃으면 해당 입력 시도를 중단합니다.
- 채팅방으로 돌아오면 입력창에 Backspace를 3회 입력하고 같은 명령을 `@`부터 다시 시작합니다. 수동 입력 중이었다면 수동 명령을 다시 시작합니다.
- 처음 시작할 때는 Backspace를 입력하지 않으며, 입력창에 남은 글 때문에 대기하지 않습니다.
- 마지막 Enter로 이미 전송한 명령은 포커스를 잃더라도 중복 전송하지 않습니다.

## 어종 미확인 기록 복구

- `기록이 누락된 어종 찾기`가 횟수 공백뿐 아니라 기존에 저장된 어종 미확인 기록도 검사합니다.
- 오늘 날짜·사용자·낚시 횟수·일반/추가 낚시 구분과 기존 보상 정보가 맞는 후보가 확인되면 같은 기록의 어종과 누락된 크기·등급을 갱신합니다.
- 기존 기록 ID·시각·획득 골드·경험치를 유지하며, 중복 기록을 추가하지 않습니다. 변경 내용은 자동 저장됩니다.
- 버튼을 누르면 최근 읽은 대화로 즉시 검사합니다. 히스토리 창 때문에 낚시가 일시중단된 상태에서도 새 낚시 결과를 기다리지 않습니다.
- 앱 실행 후 아직 대화를 읽지 않았다면 다음 첫 대화 수집 때 검사합니다. 대화에 근거가 없거나 후보가 모호한 기록은 미확인 상태로 유지합니다.

## 자동어 처리 및 진단

- 응답 없는 수동 명령이 다음 자동어 응답을 가져가던 경우와 별도 메시지로 전달되는 자동어 카드 처리를 보완했습니다.
- `@`부터 첫 Enter까지의 키 입력을 제한적으로 기록하여 다른 키의 개입 여부를 진단할 수 있도록 했습니다. 진단 로그는 실행 파일 옆 `debug/fishing-macro.log`에 저장됩니다.

## 검증 및 업데이트

- 자동 테스트 174개 통과: 입력 순서, 최대 2회 검사 시점, 포커스 이탈·재개, 기존 저장 기록의 어종 갱신·중복 방지·파일 저장 등을 검증했습니다.
- 사용자 환경에서 현재까지 기본 동작을 확인했습니다. 자동어는 약 2,000회 이상의 낚시 이후 출현한다는 사용자 관찰에 따라, 장시간 실행에서 실제 자동어 감지·해제는 추가 검증이 필요합니다.
- 기존 프로그램을 종료하고 `FishingMacro_v_1_4_0.exe`를 기존 실행 파일과 같은 폴더에서 실행하세요. `fishing-macro-history` 폴더는 유지하세요.
