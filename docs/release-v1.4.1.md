# v1.4.1 패치노트

자동어를 히스토리에서 인식하고도 낚시 제어에는 반영하지 못해 낚시가 반복되는 결함을 수정했습니다.

## 자동어 제어 누락 수정

- 과거 낚시 횟수에 공백이 있으면 제어용 응답 매칭에서 미응답 명령이 누적되고, 자동어 응답이 오래된 명령에 연결되어 최신 명령은 응답 없음으로 남는 경우를 확인했습니다.
- 기록 처리에서 새로 인식한 내 자동어를 별도의 제어 신호로 전달합니다. 이 신호는 과거 횟수 재검증이나 새 명령 판별 단계에서 제외되지 않고 수동 해제 사이클로 연결됩니다.
- 답장이 없는 수동 명령이 다음 낚시의 자동어 응답을 가져가지 않도록 기록 처리의 대기열도 정리했습니다.
- 같은 자동어 메시지를 반복 복사했을 때 신호를 중복 발생시키지 않으며, 기존 대화의 자동어와 다른 사용자에게 연결된 자동어는 새 해제 신호로 사용하지 않습니다.

## 적용 범위

- v1.4.0에서 자동어 경고 뒤에도 낚시가 반복되어 이용 제한을 받은 사례가 보고되었습니다. 이번 수정은 해당 로그에서 확인한 기록·제어 간 신호 누락 경로를 대상으로 합니다.
- 낚시 및 수동 명령의 입력 순서, 0.5초/2.5초의 최대 2회 검사, 포커스 복귀 시 Backspace 3회 처리와 히스토리 복구 기능은 유지합니다.
- 응답을 끝내 확인하지 못하면 다음 사이클을 진행하는 기존 동작은 유지됩니다. 모든 자동어 감지 실패 가능성을 해소했다고 보장하는 릴리즈는 아닙니다.

## 검증 및 업데이트

- 자동 테스트 179개 통과: 과거 횟수 공백 뒤 자동어 감지, 수동 명령으로의 전환, 미응답 수동 명령 처리, 다른 사용자 분리와 반복 복사 중복 방지를 검증했습니다.
- 로그를 바탕으로 구성한 로컬 재현 테스트에서 수정 전 실패와 수정 후 통과를 확인했습니다. 실제 게임에서의 자동어 출현·해제 및 장시간 실행은 재검증하지 못했습니다.
- 기존 프로그램을 종료하고 `FishingMacro_v_1_4_1.exe`를 기존 실행 파일과 같은 폴더에서 실행하세요. `fishing-macro-history` 폴더는 유지하세요.
