# v1.2.0 패치노트

## 핵심 요약

- **월드 보스 조우 기록 지원**: 누락되던 월드 보스 조우를 레이드로 인식하고 보상과 전투 정보를 저장합니다.
- **레이드 전용 히스토리**: 어종용 표 대신 보스명, 조우 유형, 데미지, 보상, HP를 한눈에 확인할 수 있습니다.
- **여러 보스 지원**: 크라켄으로 고정하지 않고 메시지에서 보스명을 읽으며, 월드 보스와 잔향을 구분합니다.

## 자세한 변경사항

### 월드 보스 인식 및 기록

- `월드 보스 <이름> 조우!` 응답과 후속 보스 카드를 인식합니다.
- `즉시 보상: 13,870G`와 `13,870 데미지` 형식의 골드 및 데미지를 읽습니다.
- 보상 골드, 타격 보상 해신석, 일일 횟수 달성 보상 골드를 각각 저장합니다. 달성 보상을 일반 보상에 중복 합산하지 않습니다.
- 보스 카드의 남은 HP, 최대 HP, HP 백분율을 저장합니다. HP는 조우 당시 값입니다.
- 기존 명령 순서에 따른 응답 연결을 유지하여 여러 사용자의 응답이 겹칠 때에도 해당 사용자의 기록에 연결합니다. 반복 복사 시 같은 조우를 중복 추가하지 않습니다.
- 기존 잔향 인식과 보상 기록도 유지합니다.

### 레이드 전용 화면

- 레이드 탭 열을 시간 / 보스명 / 조우 유형 / 데미지 / 보상 골드 / 해신석 / 달성 보상 골드 / 남은 HP / 최대 HP / HP(%)로 변경했습니다.
- 상단에 레이드 보상과 달성 보상을 분리하고 조우 횟수, 총 데미지, 해신석 합계를 표시합니다.
- 레이드에서는 어종 등급 선택을 비활성화합니다. 다른 탭으로 돌아가면 이전 등급 선택이 유지됩니다.
- 열 제목 클릭 정렬을 지원합니다. 일반 기록 화면과 레이드 화면을 전환하면 최신 시간순으로 정렬됩니다.
- 전체 탭에서도 확인된 보스명을 표시합니다.

### 저장 및 호환성

- 기존 일일 CSV에 보스명·조우 유형·HP 필드를 추가했습니다.
- 구 버전 CSV도 불러올 수 있으며, 당시 저장되지 않았던 항목은 `—`로 표시합니다.
- 이전 버전에서 누락된 조우를 소급 복구하지는 않습니다.
- 다른 보스도 같은 메시지 양식이면 인식합니다. 별도의 양식을 사용하는 보스는 해당 복사 원문에 따른 추가 대응이 필요할 수 있습니다.

## 검증 및 업데이트

- 자동 테스트 93개 통과: 제공된 월드 보스 원문, 다른 보스명, 사용자 응답 겹침, 반복 복사, 잔향, CSV 저장·불러오기, 레이드 화면 전환 등을 확인했습니다.
- 실제 카카오톡 월드 보스 조우를 통한 실행 검증은 아직 진행하지 않았습니다.
- 기존 프로그램을 종료한 뒤 `FishingMacro_v_1_2_0.exe`를 받아 기존 실행 파일과 같은 폴더에서 실행하세요. 기존 `fishing-macro-history` 폴더는 유지하세요.
