# v1.2.2 패치노트

## 핵심 요약

- **새 프로그램 아이콘**: 낚싯바늘을 향하는 노란빛 물고기와 붉은 지느러미 디자인을 적용했습니다.
- 실행 파일과 프로그램 창에서 같은 아이콘을 사용합니다.

## 자세한 변경사항

- 푸른 바다 배경에 반달 비늘 3개, 기포와 해초를 담은 아이콘으로 교체했습니다.
- 512×512 PNG 원본과 16~256px의 9가지 크기를 포함한 Windows ICO를 적용했습니다.
- 프로그램 버전 표시를 `v1.2.2`로 변경했습니다.
- 낚시 동작, 예약, 히스토리 저장 방식은 v1.2.1과 동일합니다.
