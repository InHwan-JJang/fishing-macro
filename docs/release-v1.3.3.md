# v1.3.3 패치노트

여러 사람이 동시에 낚시할 때 다른 사용자의 결과가 섞여 기록되는 문제를 줄이기 위해 카운트 검증을 추가했습니다.

## 동시 낚시 결과 구분

- 기존 명령 순서 매칭에 사용자별 다음 낚시 카운트 검증을 추가했습니다. 1442회 다음 결과는 1443회인지 확인합니다.
- 응답 순서가 바뀌면 대기 중인 사용자 중 다음 카운트가 일치하는 사람에게 우선 연결합니다.
- 카운트가 맞지 않거나 여러 사용자가 같은 다음 카운트를 가지면 불확실한 결과를 기록하지 않고 debug 로그에 남깁니다.
- 제외된 결과의 어종 카드가 다른 기록에 붙지 않도록 처리했습니다. 부분 복사된 헤더의 카운트 불일치가 뒤늦게 확인되면 임시 기록을 제거합니다.
- 날짜와 일반/추가 낚시 카운트를 분리하며, 자동어는 정상 낚시 카운트를 증가시키지 않습니다.
- 보조 응답 및 한도 판정에도 같은 검증을 적용하고, 누락 복구 시 다른 사용자에게 연결된 결과를 제외합니다.

## 적용 범위

- 첫 관측 결과나 카운트 없는 메시지는 기존 순서 매칭에 의존합니다.
- 불확실한 카운트를 임의의 새 기준으로 삼지 않으므로 실제 응답이 누락된 경우 후속 기록도 제외될 수 있습니다.
- 기존에 저장된 잘못된 기록을 소급 수정하지는 않습니다.
- 이전 버전의 자동어 처리, 디버깅 로그, 운영자 보상 및 누락 기록 시각 보정 기능을 모두 포함합니다.

## 검증 및 업데이트

- 자동 테스트 144개 통과: 응답 순서 역전, 다른 사용자 카운트, 중복·도약 카운트, 부분 헤더, 추가 낚시, 날짜 변경, 한도 오판 방지를 검증했습니다.
- 실제 카카오톡 입력을 통한 실행 검증은 진행하지 않았습니다.
- 기존 프로그램을 종료하고 `FishingMacro_v_1_3_3.exe`를 기존 실행 파일과 같은 폴더에서 실행하세요. `fishing-macro-history` 폴더는 유지하세요.
