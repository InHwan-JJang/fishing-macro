# 기능과 사용법

## 기본 동작

Windows 전용 카카오톡 낚시 매크로입니다. 사용자 이름은 카카오톡 대화 복사 결과에 나오는
발신자 이름과 같아야 합니다. 제목이 `낚시`로 시작하는 첫 채팅방을 대상으로 사용합니다.

1. 채팅방을 열고 사용자 이름을 입력합니다.
2. 자동 모드 또는 실행할 반복 횟수를 선택합니다.
3. 시작 버튼이나 F9로 실행합니다. F9는 시작·정지를 전환합니다.
4. 매크로 또는 대상 채팅방이 활성화된 상태에서 ESC를 누르면 정지합니다.

저장된 사용자 이름이 있으면 프로그램을 켠 뒤 약 0.6초 후 자동 시작합니다.
다른 창으로 전환하면 입력은 일시정지하고 채팅방으로 돌아오면 재개합니다.
Shift/Ctrl/Alt/Windows 키 눌림, 카카오톡 무응답, 일부 미전송·입력문 상태도 대기 조건입니다.

명령은 `@ → Enter → 낚시 → Enter` 순으로 입력합니다. 입력은 @ → 0.5초 → Enter와 낚시 → 0.5초 → Enter 순서입니다.
전송 후 다음 입력까지 3초 동안 결과를 확인하며 정상 동작의 목표 주기는 4초입니다.
대기 중에는 `2.5초 후 낚시를 실행합니다` 형태의 카운트다운과 예상 전체 남은 시간을 표시합니다.
대기 시간이 지나도 결과 처리가 남아 있으면 `낚시 결과를 확인하는 중`으로 표시합니다.

첫 낚시 답장으로 오늘 횟수와 한도를 파악합니다. 자동 모드는 확인한 일일 한도까지 실행하고,
수동 모드는 지정 반복 수를 사용합니다. 답장이 없어도 계속하므로 반복 수와 성공 마릿수는 다를 수 있습니다.

## 자정 예약

`다음 날 자동 시작 예약`을 선택하면 매일 자정 5초 뒤 새 작업을 시작합니다.
기존 작업이 있으면 먼저 정지시키고 작업 스레드가 종료된 후 시작합니다.
예약 실행은 횟수 입력값과 무관하게 자동 모드로 일일 한도까지 실행합니다.

프로그램과 PC가 켜져 있어야 합니다. PC 전원 켜기나 절전 해제 기능은 없습니다.
프로그램이 실행된 채 예약 시각을 지나 절전에서 복귀하면 다음 타이머 처리 때 시작합니다.
예약 시 채팅방을 찾지 못하면 시작 실패 상태를 표시하고 다음 날 예약은 유지합니다.

## 미끼 자동 사용

`행운 부여 시 미끼 자동 사용`을 선택하면 어종명이 아닌 효과 문구에서 새 부여를 감지합니다.
일반 `행운`, 특수 행운 `만년서리의 숨결`, `만년화리의 숨결`을 각각 추적합니다.
새 부여가 감지되면 `가방`으로 미끼 보유량을 확인하고 `미끼 min(보유량, 부여 잔여 횟수)`를 사용합니다.
동시에 여러 효과가 부여되면 같은 낚시에 함께 적용되므로 가장 긴 잔여 횟수를 사용합니다.
중복 복사/카드 보완이나 기존 효과의 감소에는 재사용 요청을 만들지 않습니다.
첫 관측이 3회처럼 중간 잔여 횟수이면 기존 효과 소비로 취급하여 미끼를 자동 사용하지 않습니다.
첫 관측의 10회·20회 등은 기존 행운 정책대로 부여로 판단합니다.
미끼가 없거나 약 8초 동안 가방 응답을 읽지 못하면 건너뛰고 낚시로 돌아갑니다.
일일 한도 또는 지정 반복을 완료한 경우에는 미끼 사용을 건너뜁니다.

## 히스토리와 통계

이번 프로그램 실행 중 매크로가 읽은 내 결과만 기록합니다. 매크로 정지 중에는 읽지 않습니다.
시작 전 대화를 일괄 수입하지 않으며, 작업 정지·재시작으로 기록이 초기화되지는 않습니다.
프로그램을 다시 실행하면 오늘 기록을 자동으로 불러와 이어서 기록합니다.

| 탭 | 표시 내용 |
|---|---|
| 전체 | 모든 결과 개별 기록 |
| 어종 | 같은 날짜·사용자·어종의 기록 합산 |
| 행운 기록 | 일반/특수 행운 부여 및 소비 기록 |
| 진주 | 진주 획득 기록 |
| 도감 완성 | 실제 도감 완성 기록의 시각·크기 |
| 자동어 | 출현 기록 |
| 레이드 | 데미지·골드·해신석·달성 보상 |

모든 탭의 기본 정렬은 최신순입니다. 어종 합산은 마지막 포획 시각 기준입니다.
등급 선택과 열 제목의 기본→오름차순→내림차순 정렬은 유지됩니다.
`구간별 통계` 버튼은 기존 창의 표를 통계 화면으로 전환합니다. 다른 탭 또는 기존 선택 탭을 누르면 기록 화면으로 돌아갑니다. 등급 선택과 열 정렬은 유지됩니다.
`누적 수` 열은 개별 기록의 경우 해당 시점까지 같은 사용자·날짜·어종의 포획 수입니다.
필터를 적용해도 누적 수를 다시 1부터 세지 않습니다. 어종 탭은 합계, 구간별 창은 해당 구간 합계입니다.
어종 외 이벤트는 같은 종류의 발생 건수를 누적합니다. 이는 진주 획득량과는 별개입니다.

등급 색은 일반 검정, 레어 파랑, 에픽 보라, 전설 주황, 신화 빨강입니다.
어종 크기는 `cm`와 `m`를 모두 인식하며 화면과 CSV에서는 cm로 통일합니다.
예를 들어 어비스 37.4m는 크기(cm) 열에 3740으로 표시됩니다.
도감 판정에는 `도감 완성!`과 `최대 크기` 문구를 사용합니다.
자동어에 오늘 횟수가 없으면 마지막 확인 횟수 + 1을 순번으로 사용합니다.
이는 확인된 횟수에 기반한 추정이며 마지막 확인 횟수조차 없으면 1로 기록됩니다.

### 판매수익 구간

| 날짜 | 150% 구간 | 120% 구간 | 100% 구간 |
|---|---|---|---|
| 평일 | 1~500회 | 501~2000회 | 2001회 이후 |
| 주말 | 1~500회 | 501~2500회 | 2501회 이후 |

구간은 기록 시각의 한국 날짜와 오늘 낚시 횟수로 나눕니다.
실제 `획득 골드`를 합산하며 배율을 다시 곱하지 않습니다.
평균은 개별 어종이 아니라 선택한 구간·등급·행운 소비 대상의 전체 포획을 기준으로 계산합니다.
진주·레이드·달성 보상은 물고기 판매수익과 별도 집계합니다.
요일별 통계 구간과 달리, 실행 중지에 사용하는 일일 한도는 봇 답장의 값입니다.

획득 경험치가 `4EXP`처럼 명시된 경우에만 합산합니다.
`경험치: EXP (...)`처럼 증가량이 없으면 현재 경험치로 역산하지 않습니다.
어종명·골드 등 읽히지 않은 값은 추정하지 않습니다. 일부 개별 항목은 `—`로 표시합니다.

## PC 자동 종료

`PC 자동 종료` 하나로 일반 실행과 예약 실행의 종료를 제어합니다. 완료 시점의 체크 상태를 적용합니다.
예약이 없으면 현재 일일 낚시 완료 후 종료하며, 예약이 있으면 다음 예약 낚시 완료까지 기다립니다.
예약으로 시작한 낚시가 완료되면 예약 체크를 해제하고 설정에도 저장한 후 종료합니다.
대기 중 예약 해제 시 현재 일일 한도가 완료된 상태라면 종료 카운트다운을 시작합니다.
자동 종료 해제 또는 PC 종료 취소는 예약 완료 후 종료 대기와 카운트다운을 취소합니다.
일일 한도 완료일 때만 60초 카운트다운 뒤 Windows 종료를 요청합니다.
지정 횟수 완료, 오류, 수동 정지는 종료 조건이 아닙니다.
`PC 자동 종료` 체크 해제 또는 새 작업 시작으로 취소할 수 있습니다.

PC 종료 옵션은 앱을 새로 켤 때 꺼져 있으며 저장 설정에서 복원하지 않습니다.
종료 전 기록 저장에 실패하면 종료 요청을 보내지 않습니다.
강제 종료 플래그는 사용하지 않으므로 다른 앱의 미저장 작업이 Windows 종료를 막을 수 있습니다.

## 저장 위치와 불러오기

실행 파일 옆 `fishing-macro-history/YYYY-MM-DD.csv`에 한국 날짜별로 저장합니다.
소스 실행 시에는 소스 폴더 옆입니다. 시작 시 오늘 파일을 자동으로 불러오고, 없으면 생성합니다.
자정을 지나면 다음 날짜 파일로 전환하며 화면도 오늘 기록을 표시합니다.
일별 파일이 없을 때만 기존 history 폴더의 해당 날짜 CSV 기록을 가져옵니다. 원본은 보존합니다.
같은 사용자·날짜·종류·오늘 낚시 순번이 같은 포획 기록은 합쳐 중복을 줄입니다.
기록 추가와 카드 보완마다 UTF-8 BOM CSV를 임시 파일에 쓴 뒤 교체합니다.
따라서 동일 낚시의 보완 정보는 같은 행을 갱신하며 중복 행을 만들지 않습니다.
저장 실패 시 화면에 알리고 5초마다 재시도합니다. 저장 실패 상태에서는 자동 PC 종료를 취소합니다.

- `히스토리 불러오기`: 매크로 정지 상태에서 CSV 또는 이전 버전 JSON을 선택합니다.
  불러온 기록은 열람 전용이며 현재 실행 기록과 합치지 않습니다.
- `오늘 히스토리`: 이번 실행 기록으로 복귀합니다. 낚시 시작 시에도 자동 복귀합니다.
- `지난 히스토리 영구 삭제`: 정지 상태에서 fishing-macro-history 폴더의 과거 CSV를 선택하여 확인 후 삭제합니다.
  오늘 기록 파일과 다른 폴더 파일은 삭제할 수 없습니다. 휴지통을 거치지 않습니다.

설정과 진단 로그는 기존 `%LOCALAPPDATA%\FishingMacro`에 유지됩니다.
기존 `history/*.json`도 그대로 남아 있으며 불러오기 대화상자에서 해당 폴더로 이동해 열 수 있습니다.
로그에는 대화 본문을 남기지 않고 복사 상태·문자 수·오류 코드를 기록합니다.

## 히스토리 열과 정렬 (2026-10-28 개편)

총 판매수익은 마릿수 요약 위에 굵은 글씨로 표시합니다. 레이드·달성 보상은 판매수익과 별개입니다.
시간, 구간, 오늘 낚시는 각각 별도 열입니다. 시간은 `YYYY-MM-DD HH:MM:SS`, 구간은
`150% / 120% / 100% / 0%`, 오늘 낚시는 `102 / 3,000` 형식입니다.
봇이 알려 준 배율을 우선 사용하고 없으면 날짜·횟수·한도로 추정합니다. 확인할 수 없으면 `—`입니다.

열 제목 클릭은 기본 → 오름차순 → 내림차순 → 기본 순으로 전환합니다.
한 번에 한 열만 정렬하고 다른 열을 누르면 해당 열의 오름차순으로 바뀝니다.
새 기록 갱신과 보기 변경 후에도 활성 정렬을 유지하며 기본으로 돌아가면 해당 보기의 원래 순서를 사용합니다.
등급은 일반·레어·에픽·전설·신화 순, 수치는 숫자 기준으로 정렬합니다.
크기는 m에서 환산한 cm 기준이며 미확인 값은 양 방향에서 마지막에 둡니다.
기존 `낚은 수 ↑ / ↓` 보기는 삭제했고 마릿수 제목으로 정렬합니다.

모두보기·등급별·도감 완성의 같은 어종 합산은 유지합니다. 합산 행의 시간·구간·오늘 낚시·크기는
최근 포획 기록을 대표값으로 표시합니다. 상세에는 별도의 대표값 안내 문구를 넣지 않습니다. 마릿수·골드·경험치는 합계입니다.
구간별은 날짜·배율·어종별로 합산하고 상단에 구간 총수익·평균을 표시합니다.
시간순과 행운 보기는 개별 기록을 표시합니다.

행운은 `행운 : 남은 N회 낚시`를 읽습니다. 최초 표시 또는 잔여 횟수가 다시 증가한 부여 결과는 행운 적용 집계에서 제외하고, 이후 소비된 낚시부터 포함합니다.
이전 잔여 횟수와 다음 결과의 오늘 낚시 순번 차이를 비교하여 마지막 사용 후 문구가 없는 결과도 포함합니다.
날짜·사용자를 분리하며 중복 복사와 자동어는 행운을 추가 소비시키지 않습니다.
시작 전에 이미 남은 행운이 있었지만 이를 읽지 못했거나 오늘 순번을 알 수 없으면
문구 없는 마지막 사용을 확정할 수 없습니다. 추정에 사용한 이전 기록이 잘못 연결되면 판정도 영향을 받습니다.
CSV/JSON에는 `luck_remaining`(명시된 잔여 횟수), `lucky`(적용 판정)가 포함됩니다.


## 크기가 없는 특수 획득물

`[파괴된 전직 장비] 9강`도 하나의 획득 카드로 인식합니다. 사용자 선택에 따라 기존 낚은 수와 판매수익에 포함합니다.
이름·등급·골드·경험치는 해당 응답 값으로 기록하고 크기는 `—`, 상세에는 `9강`을 표시합니다.
강화 수치는 `enhancement`, 그 외 원문 속성은 `card_attribute`로 JSON/CSV에 보관합니다.
크기 형식이 없다는 이유로 다음 물고기 카드를 해당 응답에 연결하지 않습니다.

## 행운 중간 시작과 등급 통계 보정

행운 첫 관측이 7회처럼 10의 배수가 아닌 양수이면 기존 행운의 소비로 판정합니다.
10회·20회 등 10의 배수이면서 이전 기록에서 예상한 잔여량보다 많을 때만 부여로 판정합니다.
이전 기록 없이 정확히 10의 배수인 잔여량부터 관측하면 부여로 간주합니다.
상세는 `행운 소비 - 남은 행운 n회`로 표시하며 마지막 소비는 0회로 표시합니다.
같은 어종을 여러 번 소비한 합산 행에는 소비 합계도 표시합니다.
등급 선택 시 상단 마릿수·판매수익·경험치 및 기타 보상 합계도 해당 등급 기록만 집계합니다.
등급 없는 진주·레이드 기록은 특정 등급 통계에서 제외되며 전체 선택 시 복원됩니다.

## 체크박스 설명 툴팁

체크박스는 `항 상 위에 표시`, `다음 날 자동 시작 예약`, `행운 부여 시 미끼 자동 사용`,
`PC 자동 종료`로 표시합니다. 마지막 세 항목은 마우스를 약 0.45초 올리면 설명이 표시됩니다.
예약 툴팁은 오전 12시에 시작으로 표시하되 실제 실행은 기존 자정 5초 대기를 유지합니다.
미끼는 일반/특수 행운 새 부여 문구에 표시된 잔여 횟수를 기준으로 사용합니다.

## 특수 행운 표시와 저장

행운 보기에는 일반 행운과 두 숨결의 소비 기록을 함께 표시합니다.
상세에는 `행운 소비 - 남은 행운 n회`, `특수 행운(만년서리의 숨결) 소비 - 남은 횟수 n회`
등으로 효과를 구분하며 함께 적용되면 각각 표시합니다. 마지막 소비도 별도로 추적합니다.
CSV에는 frost_remaining/fire_remaining 및 각 적용/부여 판정을 저장합니다.
과거 CSV에 없던 숨결 정보는 복원할 수 없습니다.

## 프로그램 종료

메인 창의 `종료` 버튼은 매크로 작업을 정지하고 기록을 저장한 뒤 프로그램을 닫습니다.
PC 종료 요청을 보내는 버튼이 아닙니다. PC 자동 종료를 취소하려면 해당 체크박스를 해제합니다.

## 포획 응답과 결과 수집 시점

일반 낚시 성공, 강한 입질, 대어 출현 모두 포획 결과로 기록합니다.
강한 입질 뒤의 에픽 어종 카드도 이름·크기·등급·골드·경험치에 연결합니다.
명령 전송 약 0.5초 뒤부터 3초 대기 구간 중 반복해서 결과를 읽습니다. 3초를 모두 기다린 후 처음 읽는 방식이 아닙니다.
히스토리 표의 행 높이는 글꼴과 화면 배율에 맞춰 계산합니다.

## 문구 독립 판정 및 4초 사이클 (최신)

명령 발신자와 봇 응답의 FIFO 연결은 유지합니다. 성공 감탄 문구 목록은 사용하지 않습니다.
오늘 낚시와 획득 골드/경험치 구조로 포획 결과를 식별하고, 종류가 아직 불명확한 응답은
대기시킨 뒤 [이름] 크기/강화 수치 등 카드 구조로 확정합니다. 명시적인 쿨다운은 후보에서 제외합니다.

정상 입력 시간표: 0초 @, 0.5초 Enter 후 바로 낚시, 1초 Enter로 전송,
1.5초 첫 결과 복사, 4초 다음 @ 입력 시작. 입력 확인·결과 확인 시간은 해당 대기 구간에 포함합니다.
결과 복사는 1회 최대 대기 예산 0.8초, 전송 후 3초 만료 전 정리 여유 0.2초로 제한합니다.
남은 시간이 0.5초 미만이면 새 복사를 시작하지 않습니다. 일시정지·카톡 무응답·OS 호출 지연은
정확한 실시간 주기를 보장할 수 없으며 키 입력을 강행하지 않습니다.

## 평균 골드 집계 정책 (최신)

표의 개별 행 평균 골드 열은 제거했습니다. 전체 탭 기본 보기에서는 평균을 표시하지 않습니다. 어종 탭은 전체 어종의 포획당 평균을 상단에 표시합니다.
- 구간별 통계: 각 날짜·구간에 낚은 모든 어종의 판매합계와 포획당 평균을 상단에 표시.
- 등급 선택: 선택 등급 전체 어종 평균. 등급 열 정렬: 등급별 평균을 각각 표시.
- 행운 기록: 일반/특수 행운을 소비한 물고기의 판매금액 평균. 부여만 받은 결과는 제외.
- 진주/자동어/레이드/도감 완성: 평균 표시 없음.
골드가 확인된 물고기만 분모에 포함하며 0G는 포함합니다. 여러 행운 효과가 겹쳐도 포획은 한 번만 셉니다.
어종별 평균들을 다시 평균 내지 않고, 실제 개별 포획의 골드 합계/확인 포획 수로 계산합니다.

## 기본 정렬 화살표

기본 최신순도 시간 열에 `시간 ▼`로 표시합니다. 시간 오름차순 선택 시 `시간 ▲`가 됩니다.
다른 열의 사용자 정렬을 기본으로 되돌리면 최신순과 시간 ▼ 표시로 복귀합니다.
구간별 통계 버튼은 활성 상태일 때 눌린 모양으로 표시하며 새 창을 만들지 않습니다.

## 버전 표시

메인 창 우측 하단에 빌드 버전을 작은 글씨로 표시합니다. 현재 정식 릴리스는 v1.1.0입니다.
# 월드 보스 및 레이드 전용 기록 (1.1.1-dev)

- 레이드 탭은 시간 / 보스명 / 조우 유형 / 데미지 / 보상 골드 / 해신석 / 달성 보상 골드 / 남은 HP / 최대 HP / HP(%) 전용 열을 표시합니다.
- 월드 보스명은 응답에서 읽으며 크라켄으로 제한하지 않습니다. 잔향과 월드 보스를 구분합니다.
- 레이드 탭에서는 어종 등급 필터를 비활성화합니다. 다른 탭으로 돌아가면 기존 등급 선택을 유지합니다.
- 즉시 보상과 달성 보상은 별도 합계이며 물고기 판매수익에 포함하지 않습니다. HP는 조우 당시 값으로, 실시간 갱신 정보가 아닙니다.
- 구 CSV는 그대로 불러오며 보스명·HP 등 저장되지 않았던 정보는 —로 표시합니다. 과거에 누락된 조우는 자동 복구되지 않습니다.
# 추가 낚시 (1.2.1-dev)

- 일반 낚시 실행은 일일 한도에서 정지합니다. 추가 낚시로 자동 연장하지 않습니다.
- 사용자가 다시 시작하고 첫 유효 응답이 `추가 낚시: N / M`이면 추가 낚시 모드로 동작합니다. 자동 횟수는 M에 도달하면 정지하고 수동 횟수는 설정한 반복 수 또는 추가 한도에서 정지합니다.
- 기록의 오늘 낚시 열에는 `추가 N / M`, 구간에는 0%, 획득 골드·EXP에는 0을 표시합니다. 실제 후속 어종 카드에서 이름·등급·크기를 읽습니다.
- 추가 한도 완료는 일반 일일 완료와 분리하여 예약/일일 완료 PC 종료 정책을 다시 실행하지 않습니다.
