# v1.2.1 패치노트

## 핵심 요약

- **추가 낚시 실행 지원**: 추가 낚시 단계에서 사용자가 매크로를 다시 시작하면 추가 한도까지 진행합니다.
- **추가 낚시 히스토리 수정**: 어종명이 `일반`으로 저장되고 등급·크기가 누락되던 문제를 해결했습니다.
- **기존 일일 한도 정지 유지**: 일반 낚시는 일일 한도에서 멈추며, 자동으로 추가 낚시를 시작하지 않습니다.

## 자세한 변경사항

### 추가 낚시 실행 및 종료

- `추가 낚시: N / M` 응답을 일반 일일 완료 안내와 구분합니다.
- 실행 후 첫 유효 응답이 추가 낚시라면 추가 낚시 모드로 전환합니다. 시작 전 횟수를 별도로 조회할 필요가 없습니다.
- 자동 횟수 설정에서는 응답에 표시된 추가 한도까지 진행하고 정지합니다. 수동 횟수 설정에서는 지정한 반복 수 또는 추가 한도에 도달하면 정지합니다.
- 기존 대화의 일일 한도 달성 안내 때문에 추가 낚시가 한 번 만에 중단되던 문제를 수정했습니다.
- 일반 낚시 도중 일일 한도가 완료되면 기존처럼 정지합니다. 추가 낚시를 하려면 사용자가 다시 시작해야 합니다.
- 추가 한도 도달 시 `추가 낚시 한도 도달`을 표시합니다. 추가 한도 완료는 일반 일일 완료와 분리하며, 일일 완료용 예약·PC 종료 처리를 다시 실행하지 않습니다.
- 기존 명령 입력과 대기 시간은 유지합니다.

### 히스토리 인식 및 표시

- 응답의 `[일반] 개구리 · 16.4cm` 같은 요약 줄을 어종 카드로 오인하던 문제를 수정했습니다.
- 후속 실제 어종 카드에서 이름·등급·크기를 읽어 같은 기록을 보완합니다. 사용자 명령 순서에 따른 응답 연결은 유지합니다.
- 오늘 낚시 열은 `추가 2 / 1,000` 형태로 표시하여 일반 낚시와 구분합니다.
- 추가 낚시 기록은 구간 `0%`, 획득 골드 `0`, 획득 EXP `0`으로 저장하고 상세에 재화·경험치가 없음을 표시합니다.

### 저장 및 호환성

- 일일 CSV에 추가 낚시 단계를 구분하는 선택 필드를 추가했습니다. 구 버전 CSV도 계속 불러올 수 있습니다.
- 기록 병합 및 행운 추적 시 일반 낚시와 추가 낚시의 같은 순번이 혼동되지 않도록 분리했습니다.
- 이미 잘못 저장된 과거 기록을 자동으로 복구하지는 않습니다.

## 검증 및 업데이트

- 자동 테스트 96개 통과: 추가 응답과 후속 카드 연결, 반복 복사, CSV 저장·불러오기, 추가 단계 연속 실행 및 일반 한도 정지를 검증했습니다.
- 실제 카카오톡 입력을 통한 추가 낚시 검증은 아직 진행하지 않았습니다.
- 기존 프로그램을 종료하고 `FishingMacro_v_1_2_1.exe`를 기존 실행 파일과 같은 폴더에서 실행하세요. `fishing-macro-history` 폴더는 유지하세요.
