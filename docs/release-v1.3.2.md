# v1.3.2 패치노트

누락 복구 기록에 초 단위 추정 시각을 부여하여 낚시 순번과 시간 정렬이 어긋나는 문제를 수정했습니다.

## 누락 기록 시간 보정

- 누락된 n번째 기록의 앞뒤 순번(n-1, n+1)이 존재하면 두 기록 시각의 중간값을 저장합니다.
- 여러 기록이 연속 누락되면 양쪽 기존 기록 사이에 순번대로 균등하게 시간을 배정합니다.
- 예: 100회 14:50:10, 104회 14:50:30 사이의 101~103회를 각각 14:50:15, 14:50:20, 14:50:25로 복구합니다.
- 이전 기록이 없거나 이웃 기록이 불분명한 경우, 앞뒤 시각이 같거나 역전된 경우에는 원래 복사 시각을 유지합니다.
- 초 간격이 부족하면 소수 초를 저장하고 시간 오름차순·내림차순 정렬에 반영합니다. 화면은 기존처럼 초까지만 표시합니다.
- 보정 시각은 정렬을 위한 추정값입니다. 기존에 저장된 기록은 일괄 변경하지 않습니다.

## 검증 및 업데이트

- 자동 테스트 138개 통과: 단일·연속 누락, 분 경계, 소수 초 정렬, CSV 저장·불러오기, 이전 기록 부재와 중복·역전 시각을 검증했습니다.
- v1.3.1의 자동어 처리, 디버깅 로그, 운영자 출현 보상 기능을 모두 포함합니다.
- 실제 카카오톡 입력을 통한 실행 검증은 진행하지 않았습니다.
- 기존 프로그램을 종료하고 `FishingMacro_v_1_3_2.exe`를 기존 실행 파일과 같은 폴더에서 실행하세요. `fishing-macro-history` 폴더는 유지하세요.
