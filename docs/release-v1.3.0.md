# v1.3.0 패치노트

## 누락 기록 복구

- 오늘 낚시 카운트 사이에 공백이 발견되면 복사된 대화에서 해당 기록을 한 번 검사합니다.
- 히스토리에 `기록이 누락된 어종 찾기` 버튼을 추가했습니다. 누르면 다음 낚시 결과를 복사할 때 한 번 재검사합니다.
- 오늘 날짜에 해당 카운트 후보가 하나뿐이면 골드를 확인하지 않고 추가합니다. 여러 후보가 있을 때만 다음 기록의 보유 골드에서 획득 골드와 별도 달성 보상을 뺀 값으로 판별합니다.
- 물고기뿐 아니라 진주·자동어·레이드도 복구 대상으로 검사하며, 추가 낚시 카운트는 일일 낚시 공백과 구분합니다.
- 복사된 대화에 오늘 날짜 구분선과 누락 기록이 있어야 합니다. 별도로 대화를 스크롤하거나 검색하지 않으며, 판별할 수 없는 기록은 미복구 건수로 표시합니다.

## 개별 세션 및 히스토리 표시

- 연속 누락에서 복구한 기록을 개별 세션으로 분류하고 CSV에 저장합니다.
- 레이드 탭 뒤에 `개별 세션` 탭을 추가했습니다.
- `개별 세션 낚시 제외` 체크박스로 해당 기록을 목록과 통계에서 제외할 수 있습니다.
- 어종 및 획득 EXP 미확인 경고는 1건 이상일 때만 빨간색으로 표시합니다.
- 등급 비율의 줄바꿈 폭을 창 너비에 맞춰 조정하여 창을 넓혀도 신화 비율이 고정 폭에서 줄바꿈되던 문제를 수정했습니다.

## 검증 및 업데이트

- 자동 테스트 118개 통과: 단일·중복 카운트, 골드 누락·불일치, 연속 누락, 날짜 구분, 특수 획득물, CSV 저장, 화면 필터 및 창 크기 변경을 검증했습니다.
- 실제 카카오톡 대화에서의 실행 검증은 진행하지 않았습니다.
- 기존 프로그램을 종료한 뒤 `FishingMacro_v_1_3_0.exe`를 기존 실행 파일과 같은 폴더에서 실행하세요. `fishing-macro-history` 폴더는 유지하세요.
