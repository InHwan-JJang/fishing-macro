# 낚시 매크로

상세 문서: [docs/](docs/README.md) · 작업 인수인계: [handoff/](handoff/README.md)

Windows 카카오톡에서 제목이 `낚시`로 시작하는 채팅방에 명령을 입력합니다.
대화 읽기는 기존과 동일하게 전체 선택·복사 및 텍스트 클립보드 복원을 사용합니다.
복사 키 입력 뒤 입력창 포커스를 먼저 복원한 다음 클립보드 텍스트가 준비될 때까지 확인합니다.
포커스 복원을 대기 뒤로 미루면 실제 카카오톡에서 복사가 지연되어 횟수와 기록을 읽지 못할 수 있습니다.
복사 진단 정보(성공 여부·문자 수·오류 코드, 대화 본문 제외)는 설정 폴더의 `diagnostics.log`에
최대 약 256KB씩 두 파일로 순환 저장합니다.

## 실행과 빌드

Python 3.9 이상에서 `python fishing_macro.py`로 실행합니다. `build.bat`는 가상환경에
PyInstaller를 설치하고 `FishingMacro.exe`를 생성합니다. 새 모듈 두 개도 자동으로 포함됩니다.
검증: `python -m unittest -v test_fishing test_history_view`

## 예약과 PC 종료

- `다음 날 자동 시작 예약`: 한국 시간 기준 자정 5초 뒤 새로운 자동 모드 작업을 시작합니다.
  실행 중인 작업은 먼저 정지하며, 예약 작업은 수동 횟수 설정과 무관하게 일일 한도까지 실행합니다.
- 프로그램과 Windows가 켜져 있어야 합니다. 절전 해제나 꺼진 PC의 전원 켜기는 제공하지 않습니다.
  예약 시각을 지나 절전에서 복귀하면 프로그램이 다시 동작하는 시점에 예약을 처리합니다.
- 채팅방이 없으면 시작 실패 상태를 표시합니다. 다음 날 예약은 유지됩니다.
- `PC 자동 종료` 하나로 통합했습니다. 예약이 없으면 일일 한도 완료 후, 예약이 있으면 다음 예약 낚시 한도까지 완료 후 종료합니다.
  예약 낚시를 완료하면 예약 체크를 해제하고 저장하므로 종료가 다시 연기되지 않습니다. 앱을 새로 켜면 PC 종료 옵션은 꺼져 있습니다.
- 일일 한도 도달로 완료한 경우에만 60초 뒤 PC 종료를 요청합니다. 수동 횟수 완료, 오류, 직접 정지는
  종료 조건이 아닙니다. `PC 자동 종료` 체크 해제 또는 새 실행으로 카운트다운을 취소할 수 있습니다.
- 강제 앱 종료 옵션은 사용하지 않습니다. 다른 앱의 미저장 문서가 Windows 종료를 막을 수 있습니다.

## 기록

이번 프로그램 실행 중 매크로가 복사해서 읽은 내 낚시 결과를 기록합니다. 시작 전 대화는 가져오지 않습니다.
정지 중에는 대화를 읽지 않으므로 직접 낚시한 결과는 기록하지 않습니다.
기록은 일일 단위이며 앱을 다시 실행해도 오늘 기록을 자동 복원하고 이어서 기록합니다.

- 히스토리: 가나다순 합산, 최신 시간순 개별 기록, 등급별 버튼, 열 제목 정렬, 구간별 수익, 행운 보기,
  도감 완성, 자동어, 진주, 레이드 보기를 제공합니다.
- 등급 색: 일반 검정, 레어 파랑, 에픽 보라, 전설 주황, 신화 빨강.
- 구간: 1~500회 150%, 평일 501~2000회 / 주말 501~2500회 120%, 이후 100%.
  날짜와 구간별로 묶으며 실제 봇의 획득 골드를 합산합니다. 표시된 골드에 배율을 다시 곱하지 않습니다.
- 구간별 어종 평균은 해당 어종의 골드가 확인된 기록들의 평균입니다. 진주·레이드·달성 보상은
  물고기 판매수익에 더하지 않고 따로 표시합니다.
- 경험치 숫자가 없는 `경험치: EXP (...)` 응답에서는 획득량을 추정하지 않습니다.
- 자동어에 오늘 횟수가 없으면 마지막 확인 횟수 + 1을 출현 순번으로 기록합니다.
- 같은 카드가 반복 복사되어도 중복 기록하지 않고, 뒤늦게 들어오는 카드 정보는 기존 기록에 합칩니다.
- 실행 파일 옆 `fishing-macro-history/YYYY-MM-DD.csv`에 날짜별 CSV를 기록 변경마다 자동 저장합니다.
- `히스토리 불러오기`는 매크로 정지 상태에서만 가능하며 현재 기록과 합치지 않습니다.
  `오늘 히스토리`로 돌아갈 수 있고 낚시 재시작 시에도 현재 기록으로 전환됩니다.
- `지난 히스토리 영구 삭제`에서 선택한 과거 CSV를 확인 후 삭제합니다. 오늘 기록은 보호됩니다.
- 이전 버전의 `%LOCALAPPDATA%\FishingMacro\history` JSON도 불러오기에서 선택할 수 있습니다.

실제 카카오톡 복사 텍스트에 카드의 어종·크기·등급 등이 포함되어 있어야 해당 항목을 기록할 수 있습니다.
카드 정보가 복사되지 않는 경우 어종 미확인으로 표시하며 이미지 인식은 하지 않습니다.
여러 사람의 명령과 답장을 순서로 연결하는 기존 전제를 유지하므로 동시 사용 시 오인식 가능성도 유지됩니다.

## 미끼 자동 사용

옵션을 켜면 어종명 대신 일반 행운·만년서리의 숨결·만년화리의 숨결의 새 부여를 감지합니다.
가방 확인 후 표시된 잔여 횟수와 보유 미끼 중 작은 수만큼 사용합니다.
동시 부여는 가장 긴 잔여 횟수를 사용하며 기존 효과 감소나 중복 복사에는 다시 사용하지 않습니다.
히스토리의 행운 보기에는 숨결도 포함하며 상세에서 일반/특수 및 효과명을 구분합니다.

## 프로그램 종료

메인 창의 `종료` 버튼은 매크로 작업을 정지하고 기록을 저장한 뒤 프로그램을 닫습니다.
PC 종료 요청을 보내는 버튼이 아닙니다. PC 자동 종료를 취소하려면 해당 체크박스를 해제합니다.
